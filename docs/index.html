🚀 Instalação & Setup

Adicione o pacote ao seu projeto Django em menos de 2 minutos.

terminal 
pip install django-rule-engine
settings.py 
INSTALLED_APPS = [
    # ...
    'django_rule_engine',
]

💡 Uso no Modelo

Defina o RuleField com dados de exemplo diretamente no seu modelo.

models.py 
from django.db import models
from django_rule_engine.fields import RuleField

class CampanhaDesconto(models.Model):
    nome = models.CharField(max_length=200)
    regra = RuleField(
        verbose_name="Regra de Elegibilidade",
        example_data={
            "preco": 150.00,
            "quantidade": 3,
            "tipo_cliente": "premium"
        },
        help_text="Exemplo: preco > 100 and quantidade >= 2"
    )

    def cliente_elegivel(self, dados_pedido):
        return self.regra_field.matches(dados_pedido)

📊 Sintaxe & Operadores

Operadores suportados pela sintaxe da biblioteca rule-engine.

Operador Exemplo Descrição
== / != status == "ativo" Igualdade e desigualdade
> / >= / < / <= idade >= 18 Comparações numéricas
and / or / not ativo and not bloqueado Operadores lógicos
in "@gov.br" in email Verifica se uma substring ou elemento pertence ao conjunto
=~ email =~ ".*@edu\\.br$" Correspondência com Expressão Regular (Regex)
